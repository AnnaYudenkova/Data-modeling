# Моделирование данных
Данный проект посвящен проектированию логической модели данных для интернет-магазина брендовой одежды «Накарабине». Целью работы было создание четкой и непротиворечивой структуры данных, которая учитывает бизнес-процессы магазина (на основе Use Case диаграммы и сценариев) и обеспечивает целостность информации. Модель служит основой для последующей физической реализации базы данных разработчиками.
